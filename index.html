    시스템 소개

    실무 퍼블리싱용 디자인 시스템 가이드 사이트입니다. 새 화면을 만들 때는 토큰 목록부터 훑기보다, 아래 순서로 필요한 패턴과 컴포넌트를 먼저 고르면 됩니다.

    01 화면 유형 찾기 로그인, 검색, 상세 등 가까운 Pattern에서 시작합니다. 02 필요한 UI 확인 Pattern에 포함된 컴포넌트의 상태와 변형을 확인합니다. 03 기본 코드 복사 컴포넌트의 Quick Start 예제를 복사해 출발합니다. 04 토큰으로 조정 여백, 크기, 색상은 역할에 맞는 토큰을 선택합니다. 05 완성 전 점검 BEM, 접근성, 하드코딩 금지 원칙을 확인합니다.
    제약내용
    기술 스택정적 HTML + CSS. 프레임워크 없음
    클래스 네이밍BEM (block__element--modifier)
    수치전부 CSS 변수(토큰)로 참조. 하드코딩 금지

    더 자세한 문서는 저장소 루트의 md 파일 참고 — README.md(사용 설명서) · publishing-rules.md(퍼블리싱 규칙) · workflow.md(작업 절차) · spec.md(스펙/IA/Patterns 정의) · history.md(진행 히스토리+백로그).

    토큰

    원칙내용
    재사용 우선새 값이 필요하면 하드코딩하지 않고, tokens.css에 이미 있는 값인지 먼저 확인
    2단 구조색상은 primitive(--gray-* 등, tokens.css 안에서만 참조) / semantic(--color-text-* 등, 컴포넌트 CSS는 이것만 참조)로 분리
    이름 = px 값--spacing-4, --text-16처럼 숫자가 곧 px 값. sm/md/lg 같은 상대 표기 안 씀

    BEM 네이밍

    원칙내용
    구조block__element--modifier, 요소는 2단계까지만
    상태is- 접두사만 사용 (is-active, is-open) — is--open 같은 표기 금지
    금지스타일을 이름에 넣기(red-btn), 위치를 이름에 넣기(left-box), 번호 붙이기(box1)

    Design Tokens

    클릭하면 var(--토큰명)이 클립보드에 복사됩니다. tokens.css의 실제 값을 그대로 읽어와서 보여줍니다.

    상황별 선택 기준

    필요한 것먼저 선택할 토큰판단 기준
    본문·라벨·힌트 텍스트--text-* + --weight-*본문은 --text-14/--text-16부터, 굵기는 regular → medium → semibold 순으로 필요한 만큼만 올립니다.
    요소 사이 여백--spacing-*자식 사이 간격은 margin 대신 부모의 gap을 우선 사용합니다.
    텍스트·배경·테두리 색상--color-*컴포넌트 CSS에서는 --gray-* 같은 primitive를 직접 쓰지 않고 역할형 semantic 토큰을 선택합니다.
    모서리·높이--radius-* + --height-*이름의 숫자가 px 값입니다. 기존 컴포넌트와 같은 용도라면 같은 값을 유지합니다.
    레이어·전환·아이콘--z-* + --transition-* + --icon-*모달/토스트처럼 겹치는 UI와 인터랙션에만 사용하고 임의 수치를 새로 만들지 않습니다.

    Utilities

    화면 하나를 통째로 구성하는 컴포넌트가 아니라, HTML에 클래스 하나만 붙여서 CSS 파일을 열지 않고 바로 미세 조정하는 원자적(atomic) 도우미 클래스. 클래스명은 tokens.css의 토큰 이름과 1:1 대응된다(값이 바뀌면 클래스명도 같이 바뀌는 걸 의도적으로 보장). css/utilities.css에서 관리.

    1. 여백 — margin / padding (.m-spacing-N / .p-spacing-N)

    요소 하나에 margin 또는 padding을 4방향 동일하게 적용. 개별 컴포넌트 CSS에 여백 규칙을 새로 안 만들고 바로 붙여 쓰는 용도.

    Patterns

    새 화면을 만들 때 가장 먼저 보는 시작점입니다. 여러 Components를 조합해 실제 화면을 구성하는 UI 패턴이며, 카드는 실제 patterns/*.html을 iframe으로 그대로 띄운 것입니다.
