Dashboard

주요 현황과 통계를 카드 형태로 제공하는 화면 — Card · Chart · Table 조합

Overview

관리자 메인, 운영 현황처럼 핵심 지표를 한눈에 보여주는 화면 패턴이다. 맨 위에 card--stat 카드로 핵심 지표를 요약하고, 가운데에 추이를 Chart로, 아래에 최근 목록을 Table로 배치한다. Chart 컴포넌트는 이 패턴 때문에 새로 만들어졌다 (spec.md 6장 질문 #2 해결) — 상세는 component/chart.html 참고.

구성 요소

구획 요소
핵심 지표 card card--stat — 지표 하나당 카드 하나 (Card)
추이 chart — 세로 막대 그래프, card로 감싸서 위젯처럼 표시 (Chart)
최근 목록 table + badge — 최근 항목 5행 이내, 역시 card로 감쌈 (Table)

Guidelines

✓ 권장

  • 카드 하나 = 지표 하나 원칙 유지 (Card 컴포넌트 Guidelines 그대로 적용)
  • Chart 아래엔 항상 chart__value로 정확한 수치 표시
  • 최근 목록은 5~10행 이내로 제한하고 "전체 보기"로 상세 목록(Search + Table 패턴)으로 연결

✕ 지양

  • 핵심 지표 카드를 스크롤 없이 안 보일 정도로 늘어놓기 (4개 안팎 권장)
  • 최근 목록 Table에 Pagination까지 붙여 Search + Table 패턴과 역할을 중복시키기 — Dashboard는 요약만
  • Chart에 10개 넘는 항목을 세로 막대로 욱여넣기 (가로 막대나 별도 화면으로 분리)
