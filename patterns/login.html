서비스 인증 화면 — Input · Checkbox · Button 조합

Overview

아이디·비밀번호를 입력받아 인증을 시도하는 화면 패턴이다. 단일 컴포넌트가 아니라 Input(텍스트/비밀번호) + Checkbox + Button을 조합해서 만든다. 상단 Logo는 이 디자인 시스템의 정식 컴포넌트가 아니며, 실제 적용 시 서비스별 로고로 교체되는 자리표시자다.

구성 요소

요소 설명
Logo 시스템 컴포넌트 아님 — 자리표시자. 실제 사용 시 서비스 로고로 교체
field 아이디 입력 (Input 기본형)
field field--password 비밀번호 입력 (Input, 눈 아이콘 마스킹 토글)
checkbox 로그인 상태 유지 (Checkbox)
btn btn--primary 로그인 버튼 (Button, 화면당 주요 액션 1개)

Example

Logo(자리표시자) + field + field--password + checkbox + btn--primary

Guidelines

✓ 권장

  • 화면당 주요 액션(로그인)은 btn--primary 하나만 강조
  • 비밀번호 필드는 Input 컴포넌트의 field--password 그대로 사용 (마스킹 + 눈 아이콘 토글)
  • Logo는 실제 서비스 로고 이미지/텍스트로 교체 — 여기 표시된 회색 박스는 자리표시자일 뿐

✕ 지양

  • 로그인 버튼 외에 동급 강조 버튼(btn--primary) 추가 배치
  • Logo를 정식 컴포넌트로 취급해 별도 Variants/States를 만드는 것 (이 디자인 시스템의 컴포넌트 목록에 속하지 않음)
  • 비밀번호 필드에 새 마스킹 방식을 직접 구현 (Input의 기존 field--password 패턴 재사용)
