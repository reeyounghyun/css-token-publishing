Modal Form

데이터 등록·수정용 팝업 입력 화면 — Modal · Input · Select · Textarea · Button 조합

Overview

별도 페이지로 옮기기엔 가벼운 등록/수정 폼을 Modal 위에 올린 패턴이다. Modal 컴포넌트 그대로 data-modal-open으로 열고 data-modal-close·바깥(딤) 클릭·ESC로 닫힌다 (js/main.js가 처리). 본문은 Input·Select·Textarea를 세로로 쌓고, 하단은 취소/저장 두 버튼으로 마무리한다.

구성 요소

요소 설명
modal + data-modal-open/data-modal-close 팝업 컨테이너, 트리거로 열고 X·바깥 클릭·ESC로 닫힘 (Modal)
field 이름 등 짧은 값 입력 (Input)
select 역할 선택 — 옵션이 적어 네이티브 select 사용 (Dropdown)
textarea 메모 등 여러 줄 입력 (Textarea)
btn btn--default / btn btn--primary 취소(data-modal-close) / 저장 (Button)

Example

modal > modal__header + modal__body(field/select/textarea) + modal__footer — 트리거를 눌러서 실제로 열어볼 수 있다

새 회원 등록

Guidelines

✓ 권장

  • 필드 3~4개 이하의 가벼운 등록/수정에만 Modal Form 사용, 그 이상 복잡하면 별도 페이지(Detail Page 패턴)로 분리
  • 저장은 btn--primary, 취소는 btn--default + data-modal-close로 항상 바깥 클릭·ESC와 동일하게 닫히게
  • 모달 제목(modal__title)은 트리거 버튼 문구와 일치시켜 사용자가 같은 동작으로 인지하게

✕ 지양

  • 필드가 많아지는데도 페이지 분리 없이 계속 Modal Form에 욱여넣기 (스크롤이 길어지면 Detail Page가 적합)
  • 저장 처리 중인데 바깥 클릭으로 닫히게 방치 (입력 유실 위험 — 처리 중엔 닫힘 방지 필요, 이 문서의 정적 데모엔 미포함)
  • 모달 안에 또 다른 Modal Form 트리거를 넣어 중첩시키기
