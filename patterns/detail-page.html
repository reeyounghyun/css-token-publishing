Detail Page

선택한 데이터의 상세 정보를 조회·수정하는 화면 — Input · Textarea · Switch · Button 조합

Overview

회원 상세, 상품 상세, 게시글 상세처럼 하나의 대상을 조회·수정하는 화면 패턴이다. 짧은 값은 기본 정보 구획에 Input으로, 긴 텍스트나 on/off 설정은 추가 정보 구획에 Textarea·Switch로 나누고, 맨 아래 저장/취소로 마무리한다.

구성 요소

구획 요소
기본 정보 field — 이름·이메일 등 짧은 값 (Input)
추가 정보 textarea — 메모/소개 등 여러 줄 텍스트, toggle — 즉시 반영되는 on/off 설정 (Switch)
하단 액션 btn btn--primary 저장 · btn btn--default 취소 (Button)

Guidelines

✓ 권장

  • 저장은 btn--primary, 취소는 btn--default로 위계 구분, 항상 오른쪽 정렬
  • 선택 즉시 반영돼야 하는 설정만 Switch로 (그 외 값은 저장 버튼을 눌러야 반영되는 Input/Textarea)
  • 구획이 늘어나면 detail-page__divider로 시각적으로 분리해 스캔하기 쉽게

✕ 지양

  • Switch로 만든 설정을 저장 버튼을 눌러야만 반영되게 만들기 (즉시 반영이라는 Switch의 전제와 모순)
  • 기본 정보/추가 정보 구분 없이 모든 필드를 한 구획에 나열
  • 취소 버튼을 저장과 동일한 btn--primary로 강조해 우선순위를 헷갈리게 하기
