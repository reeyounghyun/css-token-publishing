Search Form

목록 화면 상단에서 데이터를 검색·필터링하는 기본 검색 영역 — Input · Select · Date Picker · Button 조합

Overview

회원 관리·게시판·상품 목록·사용자 조회처럼 조건으로 목록을 좁히는 화면 상단에 쓰는 검색 영역이다. Search + Table 패턴(4-2)의 상단부가 바로 이 패턴이며, 거기서는 Date Picker 컴포넌트가 없어 기간 필터를 뺐지만 Date Picker가 생긴 지금은 이 패턴에서 Input·Select·Date Picker(기간)·Button까지 전부 포함한 완전한 조합을 보여준다. Table 없이 카드형 목록이나 게시판처럼 다른 결과 뷰와도 그대로 조합해 쓸 수 있다.

구성 요소

요소 설명
field 검색어 입력 (Input)
select 카테고리/상태 필터 — 옵션이 적어 네이티브 select 사용 (Dropdown)
field-range 기간 필터 — date input 2개 + ~ 구분자 (Date Picker)
btn btn--primary / btn btn--default 검색(주요 액션) / 초기화(보조 액션) — Button

Example

간단형 — 검색어 + 검색 버튼만 (게시판 등 조건이 단순한 목록)
상세형 — 검색어 + 상태 필터(select) + 기간(field-range) + 검색/초기화
~

Guidelines

✓ 권장

  • 조건이 늘어나면 flex-wrap으로 줄바꿈, 가로 스크롤 강제하지 않기
  • 자주 안 쓰는 조건이 많아지면(6개 이상) 전부 펼치지 말고 "상세 검색" 토글 뒤로 숨기기
  • 검색은 btn--primary, 초기화는 btn--default로 위계 구분

✕ 지양

  • 날짜 조건을 텍스트 입력으로 받기 — Date Picker(field-range) 사용
  • 검색/초기화 버튼을 둘 다 btn--primary로 동급 강조
  • 간단형이면 충분한 화면에 상세형 필터를 전부 기본 노출 (조건 개수는 실제 사용 빈도에 맞춰서)
