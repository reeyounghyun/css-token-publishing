Empty State

조회 결과·데이터·권한이 없는 상황을 안내하는 패턴 — Empty State · Button 조합

Overview

Empty State 패턴은 단일 컴포넌트(Empty State)를 상황별로 어떻게 조합해 쓰는지 정의한다. 컴포넌트 자체의 Variants/States는 component/empty-state.html에 있고, 이 문서는 실무에서 자주 겹치는 세 가지 상황 — 검색 결과 없음 / 등록된 데이터 없음 / 권한 없음 — 을 나란히 비교해서 어떤 아이콘·문구·액션 유무를 골라야 하는지 보여준다.

구성 요소

상황 아이콘 액션 버튼
검색 결과 없음 돋보기 (중립) 생략 — 사용자가 검색어를 바꾸면 되므로 시스템이 대신 할 행동이 없음
등록된 데이터 없음 빈 상자 (중립) 포함 — empty-state__action으로 "추가하기"류 다음 행동 제시
권한 없음 잠금 (중립, empty-state--error 아님 — 사용자 잘못이 아니라 접근 제한 안내이므로 위험색 강조 대신 중립 유지) 선택 — 문의 경로가 있으면 btn--default로 안내, 없으면 생략

Guidelines

✓ 권장

  • 액션 버튼은 "사용자가 실제로 취할 수 있는 다음 행동"이 있을 때만 추가 (없으면 과감히 생략)
  • 권한 없음은 사용자 잘못이 아니므로 empty-state--error(위험색)로 강조하지 않고 기본형 유지
  • 같은 화면 안에서 검색 결과 없음 ↔ 등록된 데이터 없음을 구분해서 문구를 다르게 (전자는 "다시 검색", 후자는 "추가")

✕ 지양

  • 세 상황(검색/데이터/권한)에 전부 같은 아이콘·문구 재사용
  • 권한 없음 상태에 empty-state--error를 적용해 사용자 실수처럼 보이게 하기
  • 등록된 데이터 없음인데 액션 버튼 없이 방치 (다음 행동을 안내해야 함)
