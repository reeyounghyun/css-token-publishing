Date Picker

네이티브 날짜 선택, 기간 선택(2필드), JS 없이 동작

Overview

Date Picker는 특정 날짜를 선택하는 컨트롤이다. 커스텀 캘린더 UI 대신 네이티브 <input type="date">를 쓴다 — 모바일에서 OS 기본 캘린더가 뜨고 로캘 포맷팅·키보드 접근성을 브라우저가 전담해, 커스텀 캘린더를 JS로 새로 구현하는 것보다 안정적이다 (dropdown.html이 단순한 목록엔 네이티브 select를 권장하는 것과 같은 원칙). Input 컴포넌트의 field/field__box/field__input 구조를 그대로 재사용하고 type="date"만 다르다.

Quick Start

Use when

특정 날짜를 선택받을 때 사용합니다. 네이티브 input[type="date"]를 쓰면 모바일 OS 기본 캘린더·로캘 포맷팅·키보드 접근성을 브라우저가 전담합니다.

Avoid when

브라우저 기본 달력을 감추고 커스텀 캘린더 그리드를 JS로 새로 구현하지 않습니다. 자유 텍스트 입력(placeholder="YYYY-MM-DD")으로 대체하지 않습니다.

가장 자주 쓰는 기본 조합: field + input[type="date"]

Variants

스타일 변형 없음 — Input과 동일한 field 구조 하나만 쓰고, type="date"로만 구분한다.

field > field__box > input[type="date"].field__input

States

field [field--disabled] [field__error] [field--success]

Guidelines

✓ 권장

  • 선택 가능한 날짜 범위가 정해져 있으면 min/max로 제한해서 잘못된 값 자체를 못 고르게
  • 기간 선택은 field-range로 시작/종료를 나란히, 종료일 min을 시작일 값으로 걸어 역전 방지
  • 모바일의 OS 기본 캘린더 UI를 그대로 신뢰 — 별도 오버레이로 덮어쓰지 않기

✕ 지양

  • 브라우저 기본 달력을 감추고 커스텀 캘린더 그리드를 JS로 새로 구현 (접근성·로캘 대응을 처음부터 다시 만들어야 함)
  • 자유 텍스트 입력(placeholder="YYYY-MM-DD" 등)으로 대체 — 형식 오류를 사용자가 직접 맞추게 하지 않기
  • 기간 선택에서 종료일이 시작일보다 빠른 값을 min 제한 없이 그대로 허용
