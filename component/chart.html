Chart

세로/가로 막대 그래프, JS 없이 동작

Overview

Chart는 여러 값을 막대 길이로 비교하는 정적 시각화 컴포넌트다. 실시간 데이터 바인딩이나 애니메이션 JS는 없고, 막대 크기는 인라인 style="height: N%"(세로) 또는 style="width: N%"(가로)로 직접 지정한다. 대시보드 요약처럼 간단한 값 비교에 쓰고, 실시간 갱신·확대/축소 같은 인터랙티브 차트가 필요하면 별도 라이브러리를 쓴다.

Quick Start

Use when

여러 값을 막대 길이로 비교하는 간단한 시각화가 필요할 때 사용합니다.

항목이 많거나 이름이 길면 chart--horizontal 변형을 사용합니다.

Avoid when

실시간 갱신·확대/축소 같은 인터랙티브 차트가 필요하면 별도 라이브러리를 씁니다.

States

정적 시각화 컴포넌트라 hover/disabled 같은 상태 클래스가 따로 없다. 값 강조·구분은 위 Options의 is-accent/is-muted 조합만으로 표현한다.

Guidelines

✓ 권장

  • chart__value로 정확한 수치를 항상 함께 표시 (막대 길이만으로 값을 추측하게 하지 않기)
  • 비교 기준이 되는 막대(이번 달, 최고 실적 등)는 is-accent로 강조
  • 항목이 6개를 넘거나 이름이 길면 chart--horizontal로 전환

✕ 지양

  • 수치 라벨 없이 막대만 보여주기
  • 세로 막대(chart)에 긴 항목명 그대로 사용 — 라벨이 겹쳐 보임
  • 이 컴포넌트로 실시간 갱신·확대/축소 같은 인터랙티브 차트 구현 시도 (정적 시각화 전용, 필요하면 별도 라이브러리)
